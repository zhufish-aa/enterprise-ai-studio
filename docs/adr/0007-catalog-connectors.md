# ADR 0007：数据目录控制面与独立数据库适配器

状态：Accepted；阶段02实现。延续 ADR0001/0002。

## 问题

统一维护多数据库连接需要实际驱动，但控制平面不能获得对任意业务主机的连接能力。业务开发必须固定 TEST，生产只允许独立授权的连接健康与结构同步。

## 决策

API 的 Catalog 应用服务负责源、连接、映射、快照、语义版本与资源鉴权。Identity 提供身份/资源权限端口，Releases 提供运行授权失效端口；Catalog 不直接修改发布模块私有表。独立 query-worker 按环境部署，依赖 database-adapters 和 connector-transport。API 只引用私有线协议类型，不加载业务数据库驱动。

worker 只收组织/任务 ID，经 mTLS 与签名领取短租约授权计划。计划包含批准端点与秘密引用，在浏览器/API公开响应中不可见。驱动统一 query/close 接口，按数据库方言编译参数化 SELECT、定向元数据；增加类型需新增驱动、元数据方言和契约枚举，并经过真实实例验证。池配置、凭据和已解析目标地址参与指纹。

端点、CIDR、数据库与对象清单由运维 CLI 注册，公开 API 仅选择 ID。解析所有 DNS 答案并检查 CIDR，实际连接固定解析 IP，TLS 校验原 TLS server name。业务数据库最小 SELECT 权限仍是必要外层边界。

## 取舍

多一次网络跳转与私有授权协议，换取可强制部署的访问边界。首版关系描述不自动生成跨表 JOIN，复杂业务由 DBA 提供授权视图。MySQL / SQL Server 适配器已实现但未真实验证，产品中明确标注；不能从 TypeScript 构建推导兼容性。mTLS/Vault 代码不等于企业环境已验证。后续需部署实测、数据库版本矩阵、OIDC端到端和秘密轮换演练。

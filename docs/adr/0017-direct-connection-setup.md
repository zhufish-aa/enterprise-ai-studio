# ADR0017：单表单数据库连接与服务端托管凭据

状态：Accepted。用户要求采用数据库管理工具的常规连接方式，停止强制先配置多个隐藏的前置下拉项。

人类平台管理员通过单一表单填写主机/端口/库名/用户名/密码，服务端在一个元数据事务内创建端点、凭据别名和物理连接，返回安全DTO。network.manage是新增专属权限，与connection.manage同时检查；个人Token及AI工具不能调用。原先仅特权CLI登记端点的决定对该管理入口扩展，CLI继续支持高级运维预置。端点及凭据绑定只追加，不修改旧目标。

密码是writeOnly输入，使用独立密钥AES-256-GCM封装到受保护服务端存储；数据库只记录随机环境引用。对应环境connector读取并解密，错误统一脱敏。现有Vault与本地历史fixture提供方仍保留，业务及AI上下文不接触凭据。托管存储需运维负责密钥、ACL、持久化挂载、备份和孤立密文清理，不能宣称已具备企业KMS/HSM轮换。

登记时解析和固定IPv4 /32清单，connector连接时重新执行DNS/IP白名单及特殊地址检查。只允许显式本机开发TEST关闭TLS；生产和其他地址强制证书校验。选择数据库不扫描其他库，元数据仍由明确表/视图限定。生产连接登记不授予生产检查或发布权限。

采用真实PG验证成功及错误密码、真实元数据和最小权限账号；不同引擎的表单共用契约，MySQL/SQLServer依然未实测，网关保持原拒绝策略。服务器源码工作区与本决定没有跨模块直接访问彼此私有实现。

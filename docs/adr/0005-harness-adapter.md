# ADR-0005：Harness 作为可替换客户端

日期：2026-10-22 · 状态：Accepted

## 背景

DeepSeek Harness 使用 Cordis 插件体系且处于 developer preview。宿主插件 API 会演进，企业授权不能依赖某个模型行为或插件内部状态。

## 决策

插件使用原生 apply/provide 生命周期，业务工具通过稳定 REST 调用独立后端。当前锁定 @deepseek-ai/cordis 4.0.5，先提供可编译、可卸载的禁用能力骨架；实际工具注册、用户身份委托和完整宿主装载在阶段06对固定 Harness release 验证后实现。

模型参数不包含凭据、审批人身份、管理员标记或生产环境开关。宿主从当前企业用户会话提供短期委托，后端每次鉴权。插件工具可提交发布申请，不能审批或直接连接生产。

## 替代与后果

将后端嵌入 Harness 降低初始开发量但耦合会话生命周期与企业权限；直接数据库插件无法集中审计和隔离。独立 REST 增加接口维护，但支持未来 MCP、其他 AI 客户端和纯人工管理工作台。正式插件 dsh.bundle 元数据与加载配置需依据固定宿主版本验证后加入，不能臆造兼容性。

## 验证

本阶段针对真实 Cordis context 检查服务挂载/卸载，不声称已完成 Harness 端到端集成。正式工具需验证取消、重试、用户撤销、上下文隔离和 token 不进入模型轨迹。

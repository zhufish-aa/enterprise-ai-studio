# ADR0011：Harness 生成源码，平台接管版本与测试运行

状态：Accepted，阶段04/05。

最后确认的用户需求要求完整可构建代码上传，不在平台后端增加AI生成服务。本决策优先于阶段04早期“后端模型生成配置”的方案。

Harness现有Agent负责自然语言理解、原生文件编辑和调试；插件负责授权语义、有限TEST查询、源码上传和构建/预览。平台保存可选的ReportDefinition作为业务口径与查询快照，同时接受自定义React页面，不限制所有报表只能使用固定模板。不存在服务端“生成一个页面”的模型接口。

代码与查询清单同时封存；查询只能按版本内queryKey由当前访问用户执行。恢复追加版本，不改写历史。独立worker使用固定React编译配置，不执行项目脚本。源码与编译产物暂以受RLS保护的有界bytea存储，后续可通过制品端口替换为不可变对象存储。

当前无实际内核沙箱。所有编译制品preview_only，生产授权消费者显式排除；固定编译检查不是生产扫描证明。批准/签名/发布器、资源隔离和对象存储必须另行验收，不能将本ADR或编译成功当作安全隔离已完成。

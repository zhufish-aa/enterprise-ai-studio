# ADR 0015：正常网页登录与离线管理员初始化

状态：Accepted / 已编码，企业SSO/MFA仍未验收。

问题：让业务用户在网页输入开发Token没有提供可用的账号生命周期，管理员也无法通过普通登录入口进入。客户端令牌不能替代网页登录身份。

决策：添加账号密码登录、HttpOnly/Strict Cookie、刷新恢复、强制初次改密、退出撤销和用户自助改密。管理员只通过可信离线初始化获得身份；没有公网首次管理员抢占入口或固定默认密码。注册通过组织一次性邀请码，角色仅服务端定义的viewer/developer且不能自动获得资源授权。邀请消费前重新检查创建者的当前成员资格、管理及业务权限；并发兑换锁定同一邀请行。

会话、密码和邀请值仅以摘要或scrypt保存，不进入业务日志/幂等响应。Cookie写操作校验Origin和CSRF，当前角色和会话在查询worker/结果读取阶段重验。密码会话属于单因素，禁止生产数据、生产诊断和发布审批，不伪装MFA。OIDC接口与PAT SDK保持独立；原先演示Bearer仅在显式本机模式启用。

取舍：需要管理员或运维提供第一次登录身份，注册不是任意访客获取企业资源的入口。邮件验证、找回、MFA及SSO跳转不在此增量伪造。数据库限流适合当前模块化单体；企业入口代理、分布式认证和长期审计/过期会话清理需要部署层策略。

验证：真实PG和HTTP的accounts.integration测试，包括恶意注册无新用户、跨域/CSRF无新邀请、并发仅一个账号、撤权后拒绝、真实TEST统计和注销后旧结果不可读。前端注册/登录调用实际接口；不以类型检查宣称身份链路成功。

# ADR-0006：静态轻应用与平台托管记录

日期：2026-10-22 · 状态：Accepted

## 背景

轻业务应用既需要展示与报表，也常需要表单记录。若为了表单生成任意服务器代码或开放业务生产库写权限，会显著扩大安全与回滚复杂度。

## 决策

生成应用构建为 React 静态产物；表单数据使用平台固定 CRUD API。集合 schema、allowed_actions、owner/organization 行策略随 AppVersion 封存并进入审批快照。记录带 org、collection、environment、owner 与 revision；测试预览和生产运行路径分开，服务端推导环境。业务数据源保持只读。

## 替代与后果

只支持无状态页面覆盖不足；生成任意后端需更复杂长期运行沙箱、秘密、迁移和多租户运维；直接写生产库不可接受。托管 JSONB 记录适合简单表单，但不提供任意查询、跨集合事务脚本或工作流。复杂业务写操作需专门企业服务连接器和单独 ADR。

## 验证

必须验证跨组织/跨集合/跨环境 recordId、owner 伪造、系统字段注入、schema 绕过及乐观锁。静态应用回滚不回滚记录，发布只允许兼容 schema 扩展；破坏性变更走独立迁移评审。

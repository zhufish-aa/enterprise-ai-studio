# ADR 0014：个人访问令牌与明确的人类上传操作

状态：Accepted / 已编码；真实宿主交互由用户验收。

决策：受认证的人类可为自己和当前组织签发1–90天的高熵opaque token；SHA-256存储、明文一次展示。权限限read/develop，运行时与当前RBAC/资源策略求交；身份标记为委托AI客户端，不能调用human-only配置/审批/再签发。worker保留凭据ID而非秘密以便在途撤销。签发响应不进入通用幂等响应表，重复请求只能得到明确“已签发”错误。列表和撤销仅限本人，限量避免无界签发。

Harness官方ApprovalPolicy never会拒绝ask，插件不得解释为允许。AI上传仍要求官方allowed-once；失败返回明确原因。用户可通过原生站点页主动检查文件并确认上传，独立于Agent工具；仅允许工作区快照，无源码工具参数或任意系统文件。确认绑定app/root/内存快照，单次、短期且配置变化失效。

取舍：个人令牌不能伪装新鲜交互认证，所以分享范围变更应在门户人类会话执行。平台当前登录页接受身份服务Token；企业SSO交互式登录仍需后续接入，不凭空实现认证身份。宿主同一OS用户的无限原生shell依然有读取自身秘密的信任风险，不能用界面确认替代OS隔离。

验证：真实PG令牌签发/撤销/到期/跨组织/降权/实际TEST查询/日志和幂等表秘密检查；Host/Client strict编译。没有改never为ask、自动允许或以HTTP重试绕过宿主拒绝。

# ADR 0013：组织内 TEST 站点分享

状态：Accepted / 已编码，Harness由用户验收。

问题：站点链接的可见性与数据权限不同。把创建者 Token 附在链接、复用创建者查询或通过客户端隐藏按钮都会越过资源授权；分享不应构成生产发布。

决策：private/organization 两种可见性，默认私有；组织内链接公开要求同组织认证和 app.view。人类维护者才能修改。分享历史追加不可变记录，head原子切换、revision乐观并发；固定一个成功 preview_only source/build，回收权限会使旧proof失效。源码、构建管理仍使用原有成员检查。

查询使用访问者身份和绑定的queryKey，经同一安全网关校验字段/指标/行/部门/数据集权限；当前share revision在创建、租约、完成和读取重验。iframe仅接收结果，不获得Token。没有匿名、公网、生产权限签发或电子邮件邀请。

取舍：组织身份与数据授权是必要前提。静态页面也要登录。链接权限不能替代数据集授权，已看见的数据无法追回；本机地址不能给同事访问。后续外部受众需独立审批、数据分类和身份设计，不能简单增加 anonymous 开关。

证据：0005迁移的复合FK/immutable trigger/tenant RLS；真实PG的sharing.integration测试验证拒绝前无任务、访问者实际部门统计和撤回后旧结果不可读。宿主界面不计为已验收。

# ADR-0002：逻辑映射与声明式查询

日期：2026-10-22 · 状态：Accepted

## 背景

业务开发使用测试数据，生产上线后读取相同业务语义下的生产视图。AI 自由 SQL、直接连接串和任意环境切换会扩大注入、越权和测试误连生产的风险。

## 决策

逻辑数据源与物理连接分离，以不可变 source_mappings 修订和 environment head 关联。数据集版本定义单个批准视图、字段、指标及行策略；外部 API 只接收有限 QuerySpec。开发入口固定 test；运行入口由活动 deployment 和 runtime_grant 固定 production。不同 worker 身份、Vault 路径和网络双重隔离。

## 替代与后果

允许自由只读 SQL 更灵活，但 SELECT 仍可调用危险函数、造成过量扫描或读敏感字段；正则黑名单不足。初版查询能力受限，复杂 JOIN/业务逻辑通过管理员维护视图表达。增加数据目录维护成本，换取可审批、可估算和可测试的执行范围。

## 验证

复合 FK 拒绝跨环境映射；后续以注入语料、字段/指标越权、真实视图权限、超时取消和测试池访问生产拒绝测试验证完整链路。仅存在 SQL schema 不代表查询权限已经实现。

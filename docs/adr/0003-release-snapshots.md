# ADR-0003：不可变审批快照与生产授权

日期：2026-10-22 · 状态：Accepted

## 背景

若审批只针对 appId，审批后替换源码、报表、数据集、连接或受众即可扩大权限。回滚也可能恢复已经撤销的访问能力。

## 决策

审批绑定 app/report/dataset 版本、成功构建与制品摘要、映射/schema/策略修订、字段指标、受众、托管集合行为和成本上限。服务端生成 canonical snapshotDigest。所有必须审批的应用与数据负责人独立审核；申请人不可自审。部署准备不可变路径后，事务内复核当前政策并创建 runtime_grants、切换 slot。回滚创建新申请与新部署，复用历史制品但重新审核当前权限。

## 替代与后果

直接 app.approved 布尔值无法约束实际产物；JWT 永久携带生产权限不支持即时撤销；恢复旧 deployment 指针会复活旧授权。快照和授权记录增加存储与重审次数，但能建立可审计的生产访问事实。生产读仍必须结合当前访问者，不能代用创建者权限。

## 验证

自审、变更快照、并发部署、旧映射、过期申请、重复投递和撤权后回滚均需拒绝。审批数据库事实与外部静态路由通过不可变路径和单权威 slot 收敛，不假设两个系统可原子提交。

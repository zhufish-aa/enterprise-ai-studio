# ADR 0008：持久化任务、不可变语义与演示身份

状态：Accepted；阶段02实现。补充 ADR0003/0004。

## 决策

连接检查、定向元数据和 TEST 预览采用 PostgreSQL catalog_jobs 持久队列，避免业务事务等待远程数据库。任务有当前策略 epoch、连接 revision、租约30秒、attempt最多3次及终态。worker重启后过期租约可恢复；重复或过期结果不覆盖当前 attempt。并发上限4；结构快照成功后追加，失败只写安全错误码，保留旧快照。Redis仍作为后续缓存设施，本阶段不需要依赖Redis成功才能处理目录任务。

所有写 API 绑定 UUID 幂等键、调用者、组织、操作及正文/If-Match摘要。组织锁序列化权限和映射变更；业务事实、幂等回执、审计和outbox同事务。不可变数据集版本保存结构快照、字段/指标/关系语义，映射变更追加修订。授权精确到字段/指标，空范围无权；不因未来版本新增字段而隐式扩权。结果按当前身份重新校验且只允许发起人读取。

运行权限实际来源是元数据库当前账户/组织/角色/资源授权。企业JWT使用RS256/ES256、issuer、audience和远程HTTPS JWKS；管理人类身份要求批准客户端与MFA，PROD探测要求五分钟内auth_time。本地opaque session仅在明确development/test开关下启用，用真实数据库存储token hash，方便没有企业IdP的集成验收。它不是产品默认身份提供者，UI暂采用access token入口。

## 取舍与后续

PostgreSQL轮询适用于目录规模；高吞吐后迁移调度时仍应保留事实表/租约语义。组织锁降低写并发，换取易审计的撤权一致性。OIDC浏览器PKCE、身份生命周期同步、工作负载证书轮换与队列可观测性尚需企业环境补齐。生产发布授权和生产行策略没有在此阶段实现，也没有生产业务查询入口。

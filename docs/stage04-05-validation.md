- 华东筛选11,536/15，单日范围实际缩小，未来空日期返回空行；日期首尾精确为09-24和10-23。
- 编译产物包含实际桥接查询代码/CSP，无Token、数据库密码或预嵌区域销售结果。
- 当前应用成员鉴权，目录管理员没有应用成员旁路；其他组织和未授权同组织成员不能创建查询。
- 伪造生产environment、SQL、未知queryKey、异常filter不能新增query_job；无有效发布事实的PROD请求被拒绝。
- 不存在字段、未定义指标、错误图表列/Schema版本不能封存源码版本。
- 路径遍历、隐藏路径、服务器可执行文件不能产生制品。
- 实际修改源码和查询清单，新增订单明细，网关返回50行且truncated=true；恢复历史源码创建第3版，哈希对应真实字节，旧版本不可UPDATE。
- 报表定义保存与恢复产生实际历史行及不可变查询绑定；无效JSON不产生版本。
- node:fs导入构建失败、不能读取主机文件；上传package脚本不执行；错误不暴露该文件路径。
- 发布状态明确disabled，申请接口不伪造成功、不产生审批/发布事实。
- 撤销应用成员后已完成queryJob也不能读取，数据集grant保留仍不能绕过应用归属；query_job和审计保存具体应用/版本。

4. 企业OIDC/MFA、Vault/mTLS、秘密轮换、企业OS凭据代理、共享多用户Harness逐用户身份委托及Windows文件竞态仍需企业环境验收。

6. 首版源码依赖固定，不支持任意包/脚本/用户后端和本地二进制资产。制品暂存有界PG bytea；大项目、完整游标分页、分布式构建队列、多编译worker、公网服务、成员分享与托管CRUD待阶段06/07扩展。

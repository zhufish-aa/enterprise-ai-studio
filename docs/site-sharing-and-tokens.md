# 站点分享、个人令牌与手动上传

当前实现：站点默认私有；维护者可将一个成功构建的 TEST 版本设为组织内链接公开。链接不是凭据，不包含 Token。接收者必须登录同一组织；不能匿名访问，也没有公网托管。正式审批和生产发布仍未启用。

## 网页使用

登录企业门户后，左下角“个人访问令牌”创建个人凭据。名称用于区分设备；有效期可选 7/30/90 天。完整令牌只展示一次，可复制后填入 Harness 站点页的服务器配置。关闭窗口后不会再次显示；遗失时撤销并重新创建。列表显示最新 100 个记录；最多同时 20 个有效令牌，每人每天最多签发 50 个。

只读令牌可查看授权目录和应用元信息；开发令牌额外允许创建应用、源码版本、固定构建和 TEST 查询。两者权限均与用户当前角色、数据集授权、字段、行及部门策略取交集。令牌无法管理物理连接、管理员权限、审批、生产数据或继续签发令牌。令牌代表客户端委托身份，不能通过它执行要求人类交互身份的分享范围变更；该操作请在门户使用交互身份完成。

“我的应用”选中应用和已构建版本后点击“分享”。私有允许已有站点成员访问；“组织内公开”允许同组织且具有 app.view 的登录者访问链接。分享不会赋予源码读取、修改、构建或数据集权限。访问者缺少数据授权时服务端拒绝打开/查询；不会借用创建者身份。

“保存并复制”先保存设置再复制链接。“完成”保存设置；“访问站点”仅访问当前已保存链接。剪贴板被浏览器拒绝时会选中链接，提示手动 Ctrl+C，不会伪报复制成功。分享固定 source version/build；后续上传或构建不自动替换链接。改回私有会递增分享 revision，旧的非成员访问、查询结果和请求重放均被拒绝。

链接形如 /s/{shareId}?organizationId={organizationId}。门户保留该路由，登录时只选择当前身份实际所属的组织。生成站点运行在 opaque iframe 中，通过父页面将绑定 queryKey 送至 /site-shares/{shareId}/queries；Token不进入 iframe。父页每 10 秒及重新聚焦时检查分享是否仍可访问。服务器每次查询和结果读取都会校验，页面检查不是权限边界。已经被访问者看到的数据无法追回。

127.0.0.1/localhost 仅本机可访问。分享给同事需要先部署企业可达 HTTPS 门户/API，设置防火墙、身份与网络策略，并在 Harness 配置相应门户地址。当前开发服务仍绑定本机，未自动暴露内网或公网。

## Harness 0.1.4

站点列表及详情可打开分享弹窗，显示私有/组织内公开及复制链接。使用个人令牌配置宿主时，范围设置按服务端要求只读，可跳转门户用交互身份管理。插件不会调用模型工具自动扩展分享范围。

宿主0.2.1-rc.2的 ApprovalPolicy 为 ask 或 never；never 会自动拒绝所有 approval.request，与 shell 的完全权限是不同设置。AI上传工具依然遵守 allowed-once；拒绝、取消、无审批服务分别返回明确错误，不改会话策略、不回退到直接API上传。用户可自行启用审批后重试。

也可进入站点详情，点击“上传源码”，输入已配置源码工作区内的相对项目目录和版本说明，检查文件清单/大小/摘要后点“确认上传”。这是用户主动的界面操作，独立于 Agent 的确认通道，不会让被拒绝的工具调用继续执行。源码采集继续拒绝越界、链接、隐藏秘密、非法后缀和超限；文件快照仅留 Host 内存，确认随机标识 3 分钟有效且一次使用，绑定应用和根目录，修改配置会清空。Host没有通用Shell或任意文件上传接口。

## 服务端与持久化

- Migration 0005：site_share_revisions 不可变历史 + site_share_heads 当前指针，复合外键保证组织/应用/版本/构建一致，tenant FORCE RLS。
- Migration 0006：personal_access_tokens，仅保存 SHA-256 摘要、尾部提示、组织/用户、范围、期限和撤销时间。受控 SECURITY DEFINER 摘要查询仅用于身份解析；API角色无超级用户/绕过RLS权限。迁移使用受信任的特权角色。
- 分享修改要求当前人类维护者、app.develop、expectedRevision；组织内扩权时重验语义资源。撤销不依赖已失效数据集授权。同源码版本的后续构建不隐式替换既有 buildId。
- 查询记录保存 share ID/revision 和个人令牌ID/组织/范围，不保存令牌值。创建、worker租约、完成、结果读取及后台撤权巡检重新校验。
- 令牌创建专用事务不用通用 Mutations 的响应缓存，避免明文进入 idempotency_records。重复签发 key 返回 409 TOKEN_ALREADY_ISSUED；网络丢失响应时在列表撤销并重建。撤销幂等。审计只记操作者/动作/资源ID/结果，不记录秘密。

## 验证与范围

真实 PostgreSQL 集成测试：tests/sharing.integration.test.mjs 与 tests/personal-tokens.integration.test.mjs。分享测试覆盖匿名/跨组织/非维护者/AI拒绝、不可变版本、并发 revision、撤回、旧结果和重放拒绝、访问者部门查询及无生产授权；令牌测试覆盖一次性明文、摘要存储、作用域交集、组织隔离、真实查询、实时撤销/到期/停用和秘密不入日志/幂等缓存。

独立销售测试库真实返回 47,040 元/60 笔；华东范围 11,536 元/15 笔。以上不等于生产沙箱、OIDC或公网托管验收。真实 Harness 加载、界面/工具和人工上传确认仍按用户要求由用户测试。


## 网页登录方式已更新

新增账号密码登录和管理员邀请码注册，网页登录不再输入Token。首次临时密码由运维初始化并强制修改；登录后再创建个人令牌给Harness使用。Cookie人类会话可以按当前维护者权限修改分享范围；PAT继续为客户端委托身份。完整步骤见accounts-guide.md。

# 数据目录界面设计

最终实现采用冷白背景、近白侧栏、石墨文字与钴蓝操作色；主色#4263eb、正文#202430、辅助文字#657083、边界#e4e7ed。不使用大面积彩色卡片或装饰图表。正文与表格字号12–14px，主标题28px；低于断点收起导航文字但保留aria-label和title。

主工作台以列表+详情形成清晰工作流；对象选择、查询、环境状态、元数据和业务语义都直接关联真实API。连接表单只列批准目标与凭据别名，业务成员不出现连接管理导航；后端仍独立鉴权。弹窗使用原生dialog管理焦点，输入有可访问名称，键盘焦点可见，按钮有轻量按压反馈；prefers-reduced-motion关闭过渡。详情区域独立滚动，紧凑布局改为上下排列。

先使用内置ImageGen生成第二版参考图，再在React/CSS中实现组件。图片仅为视觉探索；交付截图来自运行中的真实页面。参考图与提示词设计要点在outputs/stage02，第一版已废弃。最终视觉以实际页面截图为准。

## 第二版提示词设计要点（整理记录）

生成高质量企业数据源管理SaaS桌面界面。95%冷白/浅灰与石墨文字，钴蓝#4263EB只用于关键按钮和当前选中项。约205px近白侧栏，精确中文排版、细边框、安静留白。左侧约70%数据表格，右侧30%数据源详情；清楚区分TEST/PROD。包含销售系统数据目录、数据库类型、部门、环境映射和批准连接状态。避免绿色/黄色/紫色大色块、渐变、巨型KPI、营销插画和卡片堆叠。成品应像可长期使用的专业开发者工具。

此处记录经过整理的生成说明，后续代码调整另包含提高辅助文字对比度、字号和可访问名称。使用内置图像生成工具，无CLI/API密钥模式。
